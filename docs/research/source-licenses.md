# Research Track A: Source Licenses and Legal Architecture

## 1. Legal Differentiation Framework

To maintain full compliance and protect downstream consumers, the project explicitly segregates four distinct legal layers:

```
┌────────────────────────────────────────────────────────┐
│ 1. Software Codebase (Dual MIT / Apache-2.0)           │
│    Independently authored Rust implementations         │
└───────────────────────────┬────────────────────────────┘
                            │ processes
┌───────────────────────────▼────────────────────────────┐
│ 2. Upstream Original Datasets                          │
│    • Lichess Standard: CC0 1.0 Universal               │
│    • Lichess Broadcasts: CC BY-SA 4.0                  │
│    • Historical Games: Public Domain                   │
└───────────────────────────┬────────────────────────────┘
                            │ normalizes & compresses
┌───────────────────────────▼────────────────────────────┐
│ 3. Transformed & Aggregated Artifacts                  │
│    • Masters OTB Artifact: CC BY-SA 4.0                │
│    • Elite Online Artifact: CC0 1.0 Universal          │
└───────────────────────────┬────────────────────────────┘
                            │ preserves
┌───────────────────────────▼────────────────────────────┐
│ 4. Provenance & Attribution Manifest                   │
│    Machine-readable source manifests (`sources.json`)  │
└────────────────────────────────────────────────────────┘
```

## 2. Software Licensing vs Data Licensing

### 2.1 Software Codebase License
All code written in this repository (`crates/core`, `crates/ingest`, `crates/curate`, `crates/storage`, `crates/index`, `crates/cli`) is licensed under the standard Rust community dual license:
- **MIT License** ([LICENSE-MIT](../../LICENSE-MIT))
- **Apache License, Version 2.0** ([LICENSE-APACHE](../../LICENSE-APACHE))

This allows downstream users, developers, and commercial entities maximum freedom to embed, extend, or bundle the software tools without copyleft constraints.

### 2.2 Study of `lila-openingexplorer` (AGPL-3.0)
The reference Opening Explorer developed by Lichess (`lichess-org/lila-openingexplorer`) is written in Scala/Akka and licensed under the **GNU Affero General Public License v3.0 (AGPL-3.0)**.
- **Copyleft Scope:** If any code or derivative logic is copied directly from `lila-openingexplorer`, the entire integrating codebase would be subject to AGPL-3.0 copyleft requirements, requiring source availability over network interaction.
- **Decision:** **Zero code reuse.** We do not import, translate, or copy code from `lila-openingexplorer`. Our Rust codebase is designed, authored, and verified independently from first principles.

### 2.3 Reference Opening Names (`lichess-org/chess-openings`)
Lichess publishes opening name classifications (ECO codes and opening variations) under the **CC0 1.0 Universal** dedication. This reference dataset is legally safe to integrate as metadata dictionaries without copyleft or attribution obligations.

## 3. Dataset Licensing Obligations & Derivatives

### 3.1 Creative Commons Zero (CC0 1.0) — Elite Online
Lichess explicitly releases all standard rated game archives under **CC0 1.0 Universal**.
- **Obligations:** None. CC0 relinquishes copyright and database rights to the maximum extent permitted by law.
- **Derivative Status:** Derivatives produced from CC0 data can be distributed freely under CC0 or dedicated to the public domain.

### 3.2 Creative Commons Attribution-ShareAlike 4.0 (CC BY-SA 4.0) — Masters OTB
Official Lichess broadcast exports are licensed under **CC BY-SA 4.0**.
- **Attribution Obligation (BY):** Release artifacts incorporating broadcast data must provide clear attribution to Lichess.org and the participating tournament organizers.
- **ShareAlike Obligation (SA):** Transformed, filtered, deduplicated, or binary-encoded representations of these broadcast games are legal derivative works under copyright and database law. Under the ShareAlike clause, **the compiled Masters OTB database artifacts must be distributed under CC BY-SA 4.0** (or a compatible license).
- **Separation from Code:** The CC BY-SA 4.0 license applies to the *data artifacts*, not to the software compiler or server engine. Software processing CC BY-SA data does not become copylefted provided code and data remain cleanly decoupled.

## 5. Summary of Compliance Policies

1. **No Proprietary Scraping:** Sources with restrictive compilation rights (e.g., TWIC, ChessBase online databases) are banned from the pipeline.
2. **Collection License Isolation:** Masters OTB artifacts and Elite Online artifacts are stored in separate files with separate manifests to prevent CC BY-SA 4.0 ShareAlike contagion onto CC0 online datasets.
3. **Traceability:** Every stored game retains a compact 64-bit source identifier mapping directly to its upstream ingestion record.
