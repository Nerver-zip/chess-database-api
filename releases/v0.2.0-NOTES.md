# Chess Database API v0.2.0

This release adds game, player and event discovery, position and continuation search, filtered Opening Explorer statistics, snapshot-bound pagination and portable search companions. The canonical executable and image name are `chess-database` and `chess-database-api`; the documented legacy CLI, environment and network aliases remain available. The software is licensed under MIT OR Apache-2.0.

The release is built from reviewed revision `7caff4315a43e71e509707b8126b893f7abbe815`. Existing CGB3/v1 shards, CPI/v2 indexes, `games.idx`, stable game IDs and canonical datasets remain compatible. The corresponding canonical releases are [Masters OTB R3](https://github.com/Nerver-zip/chess-database-api/releases/tag/dataset-masters-otb-r3) and [Elite Online R1](https://github.com/Nerver-zip/chess-database-api/releases/tag/dataset-elite-online-r1); their separately versioned search companions are [Masters D40](https://github.com/Nerver-zip/chess-database-api/releases/tag/search-masters-otb-r3-d40-v1) and [Elite D30](https://github.com/Nerver-zip/chess-database-api/releases/tag/search-elite-online-r1-d30-v1). Masters discovery and search metadata remain disabled by default. Dataset licensing and attribution are separate from the software license.

## Linux x86-64 installation

Download `chess-database-linux-amd64`, `chess-database-api-v0.2.0-linux-amd64.docker.tar.gz`, `chess-database-v0.2.0-manifest.json`, `LICENSE-MIT`, `LICENSE-APACHE` and `SHA256SUMS` into the same directory, then run `sha256sum -c SHA256SUMS`. For the CLI, run `chmod +x chess-database-linux-amd64` and invoke it directly. The dynamically linked binary requires the x86-64 loader, `libgcc_s.so.1`, and glibc providing symbols through GLIBC_2.34; that symbol floor does not guarantee compatibility with every Linux distribution.

For the container, run `docker load -i chess-database-api-v0.2.0-linux-amd64.docker.tar.gz`. This loads `chess-database-api:release-v0.2.0`. Set `CHESS_DATABASE_IMAGE=chess-database-api:release-v0.2.0` and follow the [Docker deployment guide](https://github.com/Nerver-zip/chess-database-api/blob/main/docs/DOCKER_DEPLOYMENT.md), using `docker compose up -d --no-build` after configuring dataset mounts. This is a Docker image archive, not a registry image. Only Linux x86-64 artifacts are supplied; GitHub also provides source archives for the tag.

For existing CPI-only datasets, retain the original snapshot, install the matching verified search companion, then reload and check collection capabilities. See [dataset releases and rollback](https://github.com/Nerver-zip/chess-database-api/blob/main/docs/DATASET_RELEASES.md) and [Search API and Evalis handoff](https://github.com/Nerver-zip/chess-database-api/blob/main/docs/SEARCH_API.md).

## Acceptance and limits

Native legacy warm and eviction-advised comparisons passed the original timing and identity gates with client and server on separate physical cores. The host was shared, eviction was best-effort, and earlier noisy failures remain recorded. Two-collection native Docker testing passed startup, discovery, mixed-traffic, reload, rollback and feature-control checks at 512 MiB and two CPUs; some filtered searches returned busy responses under concurrent load. Full-game positional indexing remains a future optional companion and is not part of the D40/D30 releases.
